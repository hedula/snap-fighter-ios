# Memory Index

短期工作記憶入口。恢復工作時先讀這裡，再進 `.development_document/`。

- 最短恢復脈絡：`current_focus_summary.md`
- 目前細節：`current_focus.md`
- 近期輕量決策：`decisions.md`
- 關係索引：`knowledge_graph.csv`（預設不要讀）

## 邊界

- 這裡放「現在正在做什麼」，不放專案慣例與已接受的決策。
- 專案慣例看 `AGENTS.md`；已接受決策看 `.development_document/1_decisions/`。
- `decisions.md` 只是決策晉升到 `1_decisions/` 之前的暫存區。
- 本目錄內容可能過期。與程式碼、測試、runtime 觀察衝突時，以後者為準。
