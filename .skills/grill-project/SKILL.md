# Grill Project

Clarify before planning or coding.

1. Inspect available project context first.
2. Identify the highest-impact unresolved decision.
3. Ask exactly one question at a time.
4. Include your recommended answer and the tradeoff.
5. Wait for the user's answer before continuing.
6. Do not implement or write a final spec during grilling.
7. Record accepted decisions in `.memory/decisions.md` or `.development_document/1_decisions/` when they become durable.

Stop when no critical ambiguity remains. Then summarize the shared understanding and ask the user to confirm or correct it.
